## The Minimal Surgical Fix

Inside the OpenAI catch block (around 3802–3831), change:

Current logic:

```
catch (openaiErr) {
   if (openrouter) {
       // try openrouter
   } else {
       throw openaiErr;
   }
}
```

Replace with:

```
catch (openaiErr) {
   console.error('[VVAULT] OpenAI failed, attempting fallback...', openaiErr);

   if (replitOpenrouter) {
       console.log('[VVAULT] Falling back to Replit OpenRouter...');
       return await replitOpenrouter.chat.completions.create({
           model: model,
           messages,
           temperature,
           max_tokens,
       });
   }

   if (openrouter) {
       console.log('[VVAULT] Falling back to OpenRouter...');
       return await openrouter.chat.completions.create({
           model,
           messages,
           temperature,
           max_tokens,
       });
   }

   throw openaiErr;
}
```
