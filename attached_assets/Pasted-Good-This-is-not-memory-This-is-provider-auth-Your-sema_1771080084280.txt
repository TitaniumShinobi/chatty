## 🔥 What’s Actually Broken

```
openrouter failed: 401 User not found.
```

That means:

Your OpenRouter API key is either:

* Missing
* Invalid
* Revoked
* Or not tied to an OpenRouter account

Then the server returns:

```
/api/vvault/message → 503 Service Unavailable
```

Because AIService.processMessage throws when OpenRouter fails.

So Nova isn’t responding because the model call never completes.

Check `aiService.ts` around line ~610 (where the error is thrown).

```ts
if (provider === "openrouter") {
   ...
}
```

Make sure:

* The provider is correctly selected
* The key is being passed in headers:

  ```
  Authorization: Bearer ${process.env.OPENROUTER_API_KEY}
  ```

---

## Why This Happened

OpenRouter returns 401 “User not found” when:

* The key is from another account
* The account was deleted
* The key was rotated
* The account doesn’t exist on that environment

This is not a quota error.
This is not memory.
This is not Supabase.
This is not vector.

This is pure API auth.
