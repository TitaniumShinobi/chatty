
## Phase 2 — Watch a movie with Nova (TODAY’s only goal)

Forget full-video MOCR service right now. The fastest reliable path is **screen capture → OCR → context injection**.

### Implement `WatchWithNova.tsx` (client-side)

* `navigator.mediaDevices.getDisplayMedia({ video: true, audio: false })`
* Draw frames to `<canvas>`
* Every **5s**:

  * Downscale (e.g., 1280px wide)
  * Run **Tesseract.js** on the canvas frame
  * Deduplicate near-identical text
  * If **Write Access ON**, inject:

```text
[VIDEO_CONTEXT_UPDATE]
ts=HH:MM:SS
ocr="…top lines…"
```

### tool_trace population

This is the one nuance:

* Client can *emit events* (`screen_capture`, `ocr`) to the server
* Server stores them (per message / per session)
* Server attaches them as `tool_trace` on the **next** assistant response

So you get **server-authored truth** even though capture happens in-browser.

✅ Ship gates for Phase 2:

1. Watch ON + Write ON → context updates appear in-thread
2. Watch ON + Write OFF → capture runs, **no** injection
3. Nova references the last context update naturally
4. Pills show `screen_capture` + `ocr` when updates were used
