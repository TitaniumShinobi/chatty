# Step 1 — Add Tracking Table

Run this once in Supabase:

```sql
create table if not exists processed_transcript_files (
  id uuid primary key default gen_random_uuid(),
  user_id text not null,
  construct_id text not null,
  source_file text not null,
  processed_at timestamptz default now(),
  unique(user_id, construct_id, source_file)
);
```

This prevents duplicate processing.

# Step 2 — Modify embedTranscripts.js

Core logic change:

### A) Fetch already processed files

```js
async function getProcessedFiles(userId, constructId) {
  const supabase = getSupabaseClient();
  const { data } = await supabase
    .from('processed_transcript_files')
    .select('source_file')
    .eq('user_id', userId)
    .eq('construct_id', constructId);

  return new Set((data || []).map(d => d.source_file));
}
```

---

### B) Filter file list

```js
const processed = await getProcessedFiles(userId, constructId);

const filesToProcess = allFiles
  .filter(f => !processed.has(f.filename))
  .slice(0, 25); // batch limit
```

### C) After successful embedding of a file:

```js
await supabase
  .from('processed_transcript_files')
  .insert({
    user_id: userId,
    construct_id: constructId,
    source_file: filename
  });
```

Only mark processed after embedding succeeds.

# Step 4 — Optional Safety Guard

Before embedding a file:

```js
const { count } = await supabase
  .from('memory_embeddings')
  .select('*', { count: 'exact', head: true })
  .eq('user_id', userId)
  .eq('construct_id', constructId)
  .eq('source_file', filename);

if (count > 0) skip;
```
