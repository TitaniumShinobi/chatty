How SimDrive differs from everyday web search

Web search = fetches public web documents (SERP + pages), then your LLM summarizes/cites.
SimDrive = fetches environment state (screen frames, UI text, game state, TV control), then your LLM interprets that local evidence.

Think:

Web search → “What does the internet say?”

SimDrive → “What is happening in this environment right now?”
