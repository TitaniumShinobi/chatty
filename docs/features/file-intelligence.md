## Scope

This feature area covers:

- document parsing and large-file handling
- OCR for image-based text extraction
- MOCR and video-oriented text analysis
- search and retrieval support for uploaded content

## What Is Stable

- Chatty treats file intelligence as a product capability, not just a one-off experiment
- OCR and MOCR docs had drifted into duplicate plans, summaries, and UI notes
- this page is now the live capability entrypoint; dated implementation detail stays in archive or reports
